# Practical Malware Analysis – Lab 6
## Lab 6-1
### Q1
>What is the major code construct found in the only subroutine called by main?

The subroutine appears to use **if-else** construct.
It calls the `InternetGetConnectedState` API to determine whether the system has an active Internet connection. If the function returns `0`, the Internet connection check fails, and execution jumps to `loc_40102B`.


![](/assets/img/malware-analysis/Pasted%20image%2020260712151841.png)

### Q2
>What is the subroutine located at 0x40105F?

The subroutine appears to be a wrapper around `printf`, as it is always called after a string is pushed onto the stack in both branches of the if-else statement.

### Q3
>What is the purpose of this program?

The program checks whether the system has an active Internet connection using the `InternetGetConnectedState` API and then displays the connection status.

## Lab 6-2

### Q1
>What operation does the first subroutine called by main perform?

Like the previous lab, the first subroutine `sub_401000` checks whether the system has an active Internet connection using the `InternetGetConnectedState` API.
The second subroutine `sub_40117F` appears to be a wrapper around `printf`, as it prints the string passed to it, indicating the connection status.

![](/assets/img/malware-analysis/Pasted%20image%2020260712231015.png)

### Q2
>What is the subroutine located at 0x40117F?

The subroutine appears to be a wrapper around the `printf` function, similar to the one used in Lab 6-1.

### Q3
>What does the second subroutine called by main do?

The subroutine `sub_401040` opens the URL `http://www.practicalmalwareanalysis.com` and uses the `InternetReadFile` API to read `0x200` bytes from the webpage into the `Buffer` variable.

![](/assets/img/malware-analysis/Pasted%20image%2020260712235354.png)

If opening the URL or reading the webpage fails, the function returns an error message.

The function then compares the first four bytes with the string `<!--`. If they match, it returns the fifth character to the caller.

![](/assets/img/malware-analysis/Pasted%20image%2020260713001658.png)

### Q4
>What type of code construct is used in this subroutine?

The function appears to use nested **if-else** statements.

### Q5
>Are there any network-based indicators for this program?

The program uses several networking APIs, including `InternetOpenA`, `InternetOpenUrlA`, and `InternetReadFile`. It uses the User-Agent string `Internet Explorer 7.5/pma` when calling `InternetOpenA` and connects to `http://www.practicalmalwareanalysis.com` through `InternetOpenUrlA`.
### Q6
>What is the purpose of this malware?

The malware checks whether the system has an active Internet connection. 
If a connection is available, it downloads data from `http://www.practicalmalwareanalysis.com`, verifies that the response begins with `<!--`, and returns the fifth character of the response. This character is later used as a command by the subsequent stages of the malware.

![](/assets/img/malware-analysis/Pasted%20image%2020260714123437.png)


## Lab 6-3

### Q1
>Compare the calls in main to Lab 6-2’s main method. What is the new function called from main?

The function is `sub_401130`
### Q2
>What parameters does this new function take?

The function prototype can be represented as:

`sub_401130(char, LPCSTR lpExistingFileName)`

It takes two parameters:
- A character representing the command.
- A pointer to an existing file name.

### Q3
>What major code construct does this function contain?

The function appears to implement a **switch case** statement with five cases and a default case.

### Q4
>What can this function do?

The function subtracts the ASCII value of `'a'` from the command character returned by the previous function.
This determines which entry in the jump table will be executed. If the character is outside the expected range (`a`–`e`), the program prints: ``` Error 3.2: Not a valid command provided ```

If the character is `a`, which mean its ascii value is `97` it will jump to this case:

![](/assets/img/malware-analysis/Pasted%20image%2020260714142358.png)

It creats a directory, its name and path is: `C:\\Temp`

If the character is `b`, which mean its asccii value is `98` it will jump to this case:

![](/assets/img/malware-analysis/Pasted%20image%2020260714143235.png)

It copies the existing file name to `C:\\Temp\\cc.exe`

If the character is `c`, which mean its asccii value is `99` it will jump to this case:

![](/assets/img/malware-analysis/Pasted%20image%2020260714143527.png)

It deletes the file `C:\\Temp\\cc.exe`

If the character is `d, which mean its asccii value is `100` it will jump to this case:

![](/assets/img/malware-analysis/Pasted%20image%2020260714144951.png)

It opens the `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` registry key and creates or updates a `REG_SZ` value named **`Malware`** with the path **`C:\Temp\cc.exe`** to achieve persistence by executing the malware at Windows startup/logon.

If it faild, it will print `"Error 3.1: Could not set Registry value"`

If the character is `e, which mean its asccii value is `101` it will jump to this case:

![](/assets/img/malware-analysis/Pasted%20image%2020260714145458.png)

It sleeps for `0x186A0` milliseconds (100 seconds).

### Q5
>Are there any host-based indicators for this malware?

From last analysis, there is many host-based indicators, like:
- The directory `C:\Temp`. 
- The file `C:\Temp\cc.exe`. 
- The registry value **Malware** under: `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`

### Q6
>What is the purpose of this malware?

The malware downloads a command from the remote server and executes one of several actions based on the returned character. These actions include creating a directory, copying or deleting a file, establishing persistence through the Windows Registry, or delaying execution.

## Lab 6-4

### Q1
>What is the difference between the calls made from the main method in Labs 6-3 and 6-4?

Unlike Lab 6-3, the functions are called inside a loop. Instead of executing only once, the loop repeats `0x5A0` times.

![](/assets/img/malware-analysis/Pasted%20image%2020260714151801.png)

### Q2
>What new code construct has been added to main?

The main function appears to include a **loop** for or while, which repeatedly executes the malware's functionality.
### Q3
>What is the difference between this lab’s parse HTML function and those of the previous labs?

The User-Agent string is different from the previous labs. It appends the value of `arg_0` to the User-Agent string.

![](/assets/img/malware-analysis/Pasted%20image%2020260714152655.png)

`arg_0` receives the value of `var_C`, which is passed as the first argument to the function.

![](/assets/img/malware-analysis/Pasted%20image%2020260714153036.png)

As a result, each iteration uses a different User-Agent string.

### Q4
>How long will this program run? (Assume that it is connected to the Internet.)

The loop will run for 0x5A0 time, and in every time it sleeps for 0x0EA60 milliseconds.
This mean it will take (0x5A0 * 0x0EA60) milliseconds, which equal to 86400000 milliseconds, or 1440 in minutes, or 1 day

The loop executes `0x5A0` (1440) times. During each iteration, the program sleeps for `0xEA60` (60,000 milliseconds).

Therefore, the total execution time is: 
- `0x5A0 × 0xEA60 = 86,400,000` milliseconds
- `1,440` minutes 
- 24 hours (1 day)

![](/assets/img/malware-analysis/Pasted%20image%2020260714153433.png)

### Q5
>Are there any new network-based indicators for this malware?

Yes. The malware uses the URL: `http://www.practicalmalwareanalysis.com/cc.htm`

The parse HTML function also generates a different User-Agent string during each iteration by appending the loop counter. It communicates using the networking APIs:

- `InternetOpenA`
- `InternetOpenUrlA`
- `InternetReadFile`

### Q6
>What is the purpose of this malware?

The malware first checks whether the system has an active Internet connection.

If a connection is available, it enters a loop that runs for approximately 24 hours.

During each iteration, it downloads a command from the remote server, extracts a command character from the HTML response, and executes the corresponding action through the switch table introduced in Lab 6-3.
